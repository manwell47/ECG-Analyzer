# ADR-022 — Repository Publication and Licensing

Status: Accepted
Date: 2026-09-14
Scope: Repository governance

## Context

Phase 18 closed with the quality gate green (66 test files, 838 tests, 181 build
modules) and the workspace had never been under version control: no `.git`
existed, so the ignore policy written in `.gitignore` had never actually been
exercised. Publication makes the first push effectively irreversible — every
committed byte persists in history, including anything shipped by mistake.

Two constraints from the project constitution apply directly. Privacy must be
default-on (AGENTS.md §18; rules §38), and dataset provenance must be documented
(AGENTS.md §28). The code also depends on third-party scientific artifacts whose
terms are independent of this repository's own: an ONNX probe model generated by
a script held here, and PhysioNet records that are fetched rather than bundled.

An implicit publishing decision would therefore be a governance defect, not a
detail. This ADR makes it explicit and inspectable.

## Decision

1. **License: Apache-2.0.** `LICENSE` carries the canonical license text with the
   appendix copyright line completed, and `NOTICE` records third-party
   attributions plus the dataset statement. `package.json` declares
   `"license": "Apache-2.0"` and stays `"private": true` — that flag prevents an
   accidental `npm publish` and is unrelated to repository visibility.
2. **Raw biomedical datasets are never distributed.** `data/raw/` and
   `data/processed/` remain git-ignored; the MIT-BIH Arrhythmia Database
   (PhysioNet, ODC-BY 1.0) is obtained by the user directly. The committed
   artifacts under `data/fixtures/` are limited to a probe model generated by a
   script in this repository and reference arrays derived from the project's own
   DSP outputs, each with provenance documentation alongside it.
3. **The engineering record is published.** `plans/` (plans, audits, checkpoints,
   ADRs, manual-verification protocols), `AGENTS.md` and `.roo/rules-code/` are
   part of the repository. The decisions, the rejected alternatives and the
   accepted residual risk are as much a product of this project as the code.
4. **The constitution files were renamed to canonical paths before the first
   commit.** `AGENTS.md.txt` → `AGENTS.md` and
   `.roo/01-medical-engineering.md.txt` → `.roo/rules-code/01-medical-engineering.md`.
   The second rename is functional, not cosmetic: the rules file previously sat
   outside `.roo/rules-code/`, so no Code-mode rules were being loaded at all.
   Every reference citing the old names was updated in the same commit, and the
   rename is recorded here rather than left implicit.
5. **The genesis brief is published** as `docs/origin-brief.md`.
6. **Line endings are normalised to LF in the object database** via
   `.gitattributes`, the repository being Windows-authored; binary assets are
   marked so they are never converted or diffed as text.
7. **Publication is a single initial commit** made from a tree on which
   `npm run check` passes, after an evidenced check that no path under
   `data/raw/` or `data/processed/` is staged. The evidence is
   `git check-ignore -v` matching those paths plus a staged-path audit.
8. **One attributed, dataset-derived figure is permitted in the interface
   screenshots** (owner decision, 2026-09-14; recorded under the rules §61 override
   protocol). The narrow reading of item 2 admitted only project-derived artifacts.
   It now additionally admits a rendered screenshot of a real MIT-BIH recording,
   subject to three conditions: mandatory attribution (record id, channel,
   "MIT-BIH Arrhythmia Database", PhysioNet, ODC-BY 1.0, source URL); no patient
   metadata from the `.hea` header comments inside the frame; and no raw dataset
   bytes entering the repository. Item 2 is otherwise unweakened — this shows a
   recording, it does not redistribute one. The operative conditions live in
   `docs/screenshots/README.md`.

## Consequences

- The public surface is explainable in one pass: license, disclaimer, dataset
  boundaries and engineering rationale are all explicit.
- Historical citations inside `plans/` that used the pre-rename filenames are
  updated in the same commit; the rename is documented here instead of being
  silently absorbed.
- Publishing `plans/` and `.roo/` exposes the internal review process, including
  rejected alternatives and accepted residual risk. This is deliberate.
- `data/fixtures/reference/signals.json` (~442 KB of the ~450 KB committed
  payload) enters history permanently. Measured before committing and judged
  acceptable; no large binary is committed.
- Nothing in this ADR asserts clinical validity or model performance. Manual
  real-browser verification remains pending and is an observation, never a gate
  (ADR-017).
- Future dataset additions must keep matching `.gitignore` exclusions and
  provenance documentation, or this decision is violated.
- **Outcome (2026-09-14).** Realised as the single root commit
  `4558bac95d12c3ae7ae47a169251a5be386ca274` on `main` — 253 files, 73,548
  insertions — pushed to https://github.com/manwell47/ECG-Analyzer with
  `origin/main` as upstream. The remote was empty beforehand, so no history
  reconciliation was needed. A post-push audit of the pushed tree itself
  (`git ls-tree -r origin/main`) confirmed its only `data/` entries are the seven
  `data/fixtures/*` files. The commit identity was set repo-locally only.
- The permitted real-record figure is a rendering of a third-party recording, not a
  redistribution of a dataset, so item 2's exclusion still holds. Attribution is a
  licensing obligation under ODC-BY 1.0 as well as a provenance one (AGENTS.md §28):
  a figure published without it would be a defect, not an omission. Because the image
  is an interface capture and not a scientific assertion, no test asserts on it
  (rules §35); the conditions are therefore enforced by the capture protocol and by
  review, which is a weaker guarantee and is accepted as such. No code changed, so
  there was no testable behaviour to cover.
